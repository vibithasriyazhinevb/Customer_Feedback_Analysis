# Customer Feedback API Bruno Collection

1. Start MongoDB and the API with `npm start` from `server`.
2. Open this `bruno` folder in Bruno.
3. Select the `local` environment.
4. Run `Create feedback`, then copy the returned feedback and customer IDs into the environment variables.
5. Run the remaining requests.

The create request is multipart and accepts an optional image or PDF attachment up to 5 MB.
