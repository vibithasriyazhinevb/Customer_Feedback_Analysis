# 📊 Customer Feedback Analysis and Service Improvement Platform

A full-stack web application that helps organizations collect, analyze, and manage customer feedback efficiently. The platform provides real-time analytics, AI-powered sentiment analysis, and interactive dashboards to improve customer satisfaction and business decisions.

---

## 🚀 Features

### 🔐 Admin Authentication
- Secure JWT Authentication
- Login & Logout
- Protected Routes
- Remember Me
- Show Password
- Forgot Password

### 📝 Customer Feedback
- Submit Customer Feedback
- Rating System (1–5 Stars)
- Service Category Selection
- Feedback Validation

### 📊 Dashboard
- Total Feedback Count
- Average Rating
- Positive, Neutral & Negative Sentiments
- Monthly Feedback Statistics
- Recent Feedback Table

### 📈 Analytics
- Sentiment Analysis
- Rating Distribution
- Monthly Trends
- Service Category Analysis
- Interactive Charts (Chart.js)

### ⚡ Real-Time Features
- Socket.IO Live Updates
- Instant Dashboard Refresh
- Real-Time Notifications

### 📂 Feedback Management
- Search Feedback
- Filter by Rating & Category
- Sort Feedback
- Edit Feedback
- Delete Feedback
- Pagination

### 📄 Reports
- Export CSV
- Export PDF

### 🌙 UI Features
- Responsive Design
- Dark & Light Mode
- Loading Animations
- Error Handling

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/customer-feedback-analysis.git
```

### Install Dependencies

```bash
npm install
```

### Create Environment Variables

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

### Start Server

```bash
npm start
```

### Run Development Mode

```bash
npm run dev
```
